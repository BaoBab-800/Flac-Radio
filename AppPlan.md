# План радио

## Общее:
1. Правильная архитектура
2. Максимальная чистота кода
3. Удобство UX

### Правила архитектуры:
1. Один файл - одна ответственность
2. Четыре слоя
 - core
 - data
 - services
 - app
 - ui 
3. Слои не должны смешиваться
4. Модели и реализации не должны смешиваться
5. Абстракции только по необходимости

### Правила чистоты кода:
1. Правильные названия файлов, классов, методов и т. д. Должно быть короткое и понятное название прочитав которые сразу можно понять о чём идёт речь
2. Комментарии должны описывать:
 - Общую идею файла блоком "Общая идея" в верхнем части файла
 - Необходимо описать каждую функцию/метод класса коротким, но содержательным комментарием
 - Нежелательно делать длинные описания

### Правила UX:
1. Пользователь с первого взгляда должен понимать что можно/нужно сделать
2. Минимализм - основа интерфейса
3. Одна страница должна отвечать за одно действие
