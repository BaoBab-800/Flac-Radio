# Flac-Radio
Flac-Radio is an open-source radio app developed as an educational project in Flutter. While still under development, the app already plays music and supports basic player functionality.

---

### Peculiarities
- FLAC streaming music support
- Background playback
- Focus on a minimalist and clean interface

---

### Development plans
- Adding the ability to create your own stations
- Improving UX for small and large screens
- Playing music from the user's device
