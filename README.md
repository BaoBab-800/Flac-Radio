# Flac-Radio
Flac-Radio is an open-source radio app developed as an educational project in Flutter.

---

### Peculiarities
- FLAC streaming music support
- Background playback
- Focus on a minimalist and clean interface

---

### Development plans
- Adding the ability to create your own stations
- Improving UX for small and large screens
- Playing music from the user's device

---

The project is open to constructive feedback and pull requests.
